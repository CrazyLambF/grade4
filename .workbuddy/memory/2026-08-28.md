## 修复：器官拼图游戏空白页（v-html + SVG 命名空间问题）

### 根因
Vue 3 中在 `<svg>` 元素上使用 `v-html` 会导致运行时错误/空白。Vue 编译器将 `<svg v-html="...">` 编译为 `createElementBlock("svg", { innerHTML: ... })`，但 `innerHTML` 赋值给 SVG 元素时浏览器以 HTML 命名空间解析，无法正确创建 SVG 子元素，可能导致渲染崩溃（页面空白）。

### 修复方案
将所有 `<svg v-html="pathString">` 改为 `<div v-html="fullSvgString">`：
- 新增 `wrapSvg(inner, size)` 辅助函数，返回完整的 `<svg xmlns="..." viewBox="..." width height>inner</svg>` 字符串。
- 模板中 4 处 `<svg v-html>` 全部改为 `<div class="organ-*-icon" v-html="wrapSvg(...)">`。
- `getSystemSvg` 也改用 `wrapSvg` 返回完整 SVG。
- 新增 `.organ-sys-icon` / `.organ-slot-icon` / `.organ-bank-icon` / `.organ-correct-icon` CSS（flex 居中容器）。
- `npm run build` 通过；dev server HTTP 200。

### 教训
**Vue 3 中 v-html + SVG 的正确做法**：不要在 `<svg>` 标签上用 v-html，改为在 `<div>` 上用 v-html 传入完整 `<svg>...</svg>` 字符串。div 的 innerHTML 会正确解析 SVG 命名空间。
